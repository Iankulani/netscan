# Compile 
```bash
gcc -Wall -Wextra -O2 -pthread -o netscan netscan.c
```
# Run
```bash
sudo ./netscan 192.168.1.1
sudo ./netscan 192.168.1.0/24
sudo ./netscan 192.168.1.1 192.168.1.20
```
